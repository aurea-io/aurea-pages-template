# aurea-pages-template

Monorepo separacion en backend, frontend
lenguaje NestJs/Fastify, React+Vite PWA

debe poder tener las funcionalidades separadas en modulos, la idea es un template completo el cual se pueda elegir las funciones que el cliente quiere y se debe poder crear un repo nuevo con esas funciones, sin incluir las demas

debe tener test para verificar que funcione con todas, y con cada una en solitario de las funciones
simil springboot initializer

tener un usuario admin para poder activar y desactivar funciones en base a la menbresia que pague el cliente, tambien si es posible gestionarlo desde un gestor externo 

las funciones son mercadopago, turnero, stock, calendario...
