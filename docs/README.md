## Convenciones

- **Definido:** decisión tomada para orientar el proyecto.
- **Propuesto:** recomendación que debe validarse durante el POC.
- **Pendiente:** decisión abierta que bloquea o condiciona una implementación.
- Las rutas y nombres de módulos son conceptuales hasta que exista código.
- Los datos de la página de referencia no deben copiarse como datos reales del producto.
