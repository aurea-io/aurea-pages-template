# Decisiones pendientes

Estas decisiones deben cerrarse antes de considerar la primera versión productiva.

| Tema | Pregunta | Impacto |
| --- | --- | --- |
| Nombre y marca | ¿Aurea Pages es el nombre definitivo? | Dominio, identidad y comercialización |
| Licencia | ¿Será privado, open source o dual? | Distribución del template |
| ORM | ¿Prisma, Drizzle o TypeORM? | Modelo, migraciones y operación |
| Monorepo | ¿pnpm, Turborepo u otra herramienta? | Build y generación de productos |
| Auth | ¿Sesiones propias o proveedor externo? | Seguridad y mantenimiento |
| Membresías | ¿Dónde se administra el plan? | Activación de módulos |
| Pagos | ¿Checkout, link o transferencia manual? | Flujo de confirmación |
| Notificaciones | ¿Correo, WhatsApp, SMS? | Recordatorios y costos |
| Archivos | ¿Dónde se almacenan fotos y logos? | Privacidad y costos |
| Hosting | ¿VPS propio o servicio administrado? | Deploy, backups y soporte |
| Facturación | ¿Se emitirán comprobantes desde la plataforma? | Alcance legal y fiscal |
| Zona horaria | ¿Una por tenant o una global? | Disponibilidad y reportes |
| Soporte | ¿Cómo se atienden incidentes? | Operación y SLA |

## Criterio de cierre

Cada decisión debe registrar alternativa elegida, motivo, impacto, responsable y fecha. Si una decisión cambia arquitectura o contratos, se actualizan los documentos relacionados antes de implementar.
