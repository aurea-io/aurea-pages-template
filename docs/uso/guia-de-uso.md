# Guía de uso

## Alta de un negocio

1. Crear el tenant.
2. Crear el usuario administrador.
3. Completar nombre, descripción, contacto y ubicación.
4. Elegir módulos y plan.
5. Configurar horarios y condiciones.
6. Publicar el enlace.
7. Generar un QR o asociar un NFC.

## Configurar turnos

1. Crear categorías.
2. Crear servicios.
3. Agregar variantes con duración y precio.
4. Definir señas y política de cancelación.
5. Definir disponibilidad.
6. Bloquear excepciones.
7. Crear una reserva de prueba.

## Operación diaria

- Revisar agenda.
- Confirmar pagos pendientes.
- Atender o marcar ausencias.
- Reprogramar cuando corresponda.
- Consultar historial.
- Cerrar el día y revisar métricas.

## Experiencia del cliente

El cliente no debería necesitar registrarse para reservar. El sistema debe pedir solo los datos necesarios, explicar condiciones antes del pago y entregar un código o enlace para consultar o reprogramar.
