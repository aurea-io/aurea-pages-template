# Módulo de clientes y fidelización

## Objetivo

Construir un historial útil sin obligar al cliente a crear una cuenta completa para cada reserva.

## Datos mínimos

- Nombre, teléfono y correo opcional.
- Historial de reservas y cancelaciones.
- Preferencias o notas internas con control de acceso.
- Consentimiento de comunicaciones.

## Fidelización

La primera versión puede contar reservas completadas y aplicar una regla configurable, por ejemplo, descuento después de cierta cantidad de visitas. La regla debe registrar su motivo y no modificar retrospectivamente reservas ya cerradas.

## Privacidad

El cliente debe poder solicitar corrección o eliminación cuando sea compatible con obligaciones legales, auditoría de pagos y necesidades operativas.
